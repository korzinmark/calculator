# Calculator

A calculator app built with vanilla JavaScript, HTML, and CSS. Supports chained operations, decimals, percentages, and full keyboard input.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Chained operations (e.g. `5 + 3 × 2 =`)
- Decimal input and percentage calculation
- Keyboard support (digits, operators, `Enter`/`=`, `Backspace`, `Escape`/`Delete`)
- Error handling for invalid operations (e.g. division by zero)

## Tech Stack

- Vanilla JavaScript (no framework)
- HTML / CSS
- ESLint for linting

## Getting Started

```bash
git clone https://github.com/korzinmark/calculator.git
cd calculator
```

Open `index.html` in a browser, no build step required.
